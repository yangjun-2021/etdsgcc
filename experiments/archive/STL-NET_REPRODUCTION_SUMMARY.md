# STL-Net 复现实验结果汇总

**数据集**: SGCC (State Grid Corporation of China)  
**样本**: 42,372 条, 窃电 3,615 (8.53%)  
**特征**: 1,034 个时间点 (PAA 压缩 → 50 段)  
**缺失率**: 25.64% → 混合插补 (稀疏列中位数, 稠密列线性插值)

---

## 实验流程

```
原始数据 (42372×1034)
  → 混合插补 (稀疏门控: 线性插值 + 中位数)
  → PAA 压缩 1034→50 段
  → 10折分层交叉验证 (每折内部:)
      a. SMOTE-Tomek 平衡 (正类→50%)
      b. 互信息特征选择 (Top 30)
      c. 超参数优化 (NSGA-II / RandomSearch)
      d. 训练 4 个基学习器 (XGB, LGB, CatBoost, NGBoost*)
      e. XGBoost 元学习器 Stacking
  → 评估: F1, AUC, Precision, Recall, Accuracy, Kappa, MCC
```

**\*NGBoost 失败**: `NGBClassifier.__init__()` 收到意外的关键字参数 `'Distribution'`，在所有折中均被跳过。

## 分析与结论

### 复现状态: ❌ 失败 — 与论文声称值存在巨大差距

1. **核心指标差距巨大**:
   - F1: 0.3423 vs 0.9447 (差距 −0.6024)
   - AUC: 0.7221 vs 0.9869 (差距 −0.2648)
   - 只有 Accuracy (89.24% vs 94.38%, −5.4%) 相对接近

2. **已知问题**:
   - **NGBoost 完全不可用**: API 不兼容 (`Distribution` 参数问题)，Stacking 集成缺少一个重要基学习器
   - **数据不匹配**: 论文使用 SGCC 数据，但此复现使用 42,372 条记录 (可能是子集或不同版本)
   - **STL-Net 论文结果异常高**: 窃电检测 (8.53% 正类率) 达到 F1=0.9447、AUC=0.9869 对于基于梯度提升树的方法而言异常高，值得怀疑
   - **超参数优化效果有限**: NSGA-II (Run 1) 和 RandomSearch (Run 2) 得到相似结果，表明性能瓶颈不在超参数

3. **最佳运行**: Run 4 (20260621_001413) 获得了所有指标的最高均值，标准差也较小，表明更稳定
